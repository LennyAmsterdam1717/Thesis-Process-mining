# Beyond Generalist LLMs: Specialist Agentic Systems for Structured Code Workflow Execution

- **Authors:** Harris Borman; Herman Wandabwa; Fusun Yu; Sandeepa Kannangara; Justin Liu; Anna Leontjeva; Ritchie Ng
- **Year / first version:** 2026 / 2026-07-16

## What they did
Compares a specialist BPMN-to-ReAct workflow generator with generalist coding agents (Roo, Cline) on tool-use exactness, process adherence, latency, tool-call errors and token cost across ten workflows.

## Key findings
Specialist generation beats generalist coding agents by 9–20 points in tool-use exactness, 2–4x in penalty-adjusted latency and with 3x fewer tool-call errors, and uses >95% fewer tokens.

## Limitations / future work
Deterministic workflows only; baselines run with default settings; future work: optimised baselines and component ablations.

## Why it matters for the thesis
Example of direction 6 measured with process-performance metrics but without process mining: an RQ could redo this comparison with discovered models and conformance.
