## What they did
pm4aa: discovers roles and work patterns from object-centric event logs of software-engineering records and turns them into AI-agent specifications; case study on Commitizen, functional tests and a user study.

## Key findings
Discovers roles and work patterns from object-centric SE logs and generates agent specifications that users found well-scoped.

## Limitations / future work
User study measures perceived alignment of specifications, not runtime agent behaviour; no comparative baseline; a single repository case.

## Why it matters for the thesis
BPM-community work (Bala, Fournier, Limonad, Metzger) on the reverse direction: process mining to design agents.
