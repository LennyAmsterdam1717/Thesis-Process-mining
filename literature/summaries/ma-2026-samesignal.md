# Same Signal, Different Semantics: A Cross-Framework Behavioral Analysis of Software Engineering Agents

- **Authors:** Wei Ma; Zhi Chen; Jingxu Gu; Tianling Li; Shangqing Liu; Lingxiao Jiang
- **Year / first version:** 2026 / 2026-05-18

## What they did
Cross-framework behavioural analysis of 64,380 SWE-bench runs from 126 configurations (43 frameworks): separates framework and LLM effects and tests whether trajectory-outcome rules transfer.

## Key findings
Swapping the framework with the LLM fixed changes every measured action feature; most behaviour–outcome rules do not transfer consistently across configurations.

## Limitations / future work
Observational, no causal claims; configurations solve different task subsets, so task difficulty confounds effects.

## Why it matters for the thesis
Strongest 2026 evidence that architecture (framework) shapes behaviour; motivates comparing designs as processes.
